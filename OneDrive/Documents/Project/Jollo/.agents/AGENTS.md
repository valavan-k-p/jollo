# LibreUIUX Integration Guidelines

This project leverages the LibreUIUX-Claude-Code AI capabilities for advanced UI/UX development.

## UI/UX Development Rules
When the user asks to build, refactor, or critique UI components:
1. **Apply Design Mastery**: Rely on the installed design mastery skills (e.g., `premium-saas-design`, `brand-systems`, `design-principles`) to ensure modern, accessible, and highly aesthetic outputs.
2. **Move Beyond Basic Frameworks**: Avoid default, simplistic "Bootstrap-era" designs. Use modern paradigms such as glassmorphism, precise spacing systems, subtle animations (framer-motion, GSAP), and typography hierarchy.
3. **Use Tailwind Strategically**: When writing Tailwind classes, focus on explicit design tokens like `shadow-md`, `p-6`, specific typography tracking classes, and unified color palettes.
4. **Follow Best Practices**: Write components in React 19 / Next.js 16 App Router format, and apply advanced TypeScript patterns as defined in the JS/TS skills.
